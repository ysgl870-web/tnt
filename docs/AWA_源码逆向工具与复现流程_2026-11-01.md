## 3. 复现方式

仓库新增脚本：tools/reverse_awa_apk.sh。

```bash
mkdir -p reverse/input
# 将 awa-main.zip 或 awa.apk 放入 reverse/input/
bash tools/reverse_awa_apk.sh reverse/input/awa-main.zip
```

脚本先校验 ZIP 只包含一个 APK，再检查 DEX 与 Manifest，然后执行：

1. JADX：生成 Java-like decompilation 输出。
2. Apktool：生成 Smali、解码资源与 Manifest。
3. 汇总输入 SHA-256、工具版本、输出文件数量与文件哈希。

结果写入 reverse/output/，该目录已加入 .gitignore。原始 APK 放在 reverse/input/，同样不会被误提交。工具需从官方仓库安装，脚本不自动下载可执行文件。

支持环境变量：JADX_BIN、APKTOOL_BIN、APKTOOL_JAR。

## 5. TNT 移植原则

TNT 已提供 AWA/黑壳能力清单与功能映射。优先采用独立实现、可验证且低隐私风险的功能：本地预设管理、JSON 校验、搜索与快捷栏布局、离线目录、用户主动触发的媒体链接处理。
